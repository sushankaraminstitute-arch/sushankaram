
  # Multi-page educational website

  This is a code bundle for Multi-page educational website. The original project is available at https://www.figma.com/design/Ba1tPz3HeiddG9Du2cUxfa/Multi-page-educational-website.

  ## Running the code

  Frontend files live in `frontend/`.

  Run `npm --prefix frontend i` to install frontend dependencies.

  Run `npm run dev` from the project root to start both the frontend and backend together.

  If you start only the frontend with `npm run dev:frontend`, also run `npm run dev:backend` in another terminal so the API routes are available.
